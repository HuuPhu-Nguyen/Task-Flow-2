# Claim-to-Evidence Matrix

This is a reviewer index for behavior implemented on `main`, not a second
guarantee contract. Normative wording and evidence status remain in
[Guarantees and non-goals](GUARANTEES.md); crash semantics remain in the
[failure model](FAILURE_MODEL.md). Automated-evidence links name focused
source tests. The experiment/report column distinguishes measured or
reproducible system evidence from contract-only proof.

## Reading the matrix

- A report is a bounded observation on its recorded commit, host, JVM,
  containers, and workload; it is not a service-level objective.
- A focused test proves its named mechanism and failure window, not every
  deployment topology.
- Current architecture and transaction flows are visualized in
  [Architecture diagrams tied to invariants](ARCHITECTURE_DIAGRAMS.md).
- Exact delivery, recovery, and non-goal wording remains authoritative in
  [Guarantees and non-goals](GUARANTEES.md) and the
  [failure model](FAILURE_MODEL.md).
